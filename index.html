FANTASY HOCKEY MANAGER
PERSONAL PROJECT · IN DEVELOPMENT

Your fantasy league.
One clear dashboard.

A personal web application concept for viewing and analyzing a Yahoo Fantasy Hockey league in one place.

Project status: Early-stage project. The application is not yet connected to Yahoo Fantasy and does not currently display live league data.

Planned features

🏆 League standings

Team rankings, records and league information.

⚔️ Weekly matchups

Head-to-head matchups and category progress where available.

🏒 Team rosters

Active players, bench players, positions and roster information.

🔎 Free agents & waivers

Available players, statistics and player comparisons.

📊 Player analytics

Goals, assists, shots, hits, blocks and other supported statistics.

📅 NHL schedule

Upcoming games to help plan fantasy roster decisions.

How it is intended to work

1. Official API: The project intends to use the official Yahoo Fantasy Sports API, subject to approval and available permissions.

2. Read-only access: All roster changes and league actions will continue to be performed directly on Yahoo Fantasy. This application is intended to retrieve and display permitted data.

3. Personal use: The initial scope is one user and one Yahoo Fantasy Hockey league.

Project scope

This is an independent personal project and is not affiliated with or endorsed by Yahoo or the National Hockey League. Access to Yahoo Fantasy data depends on API approval, permissions and applicable terms. No live data or Yahoo account connection is available on this page.
