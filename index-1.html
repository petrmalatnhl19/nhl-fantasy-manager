FANTASY HOCKEY MANAGER
PERSONAL PROJECT · IN DEVELOPMENT

Your fantasy league.
One clear dashboard.

Fantasy Hockey Manager Dashboard is a personal web-app concept for viewing and analyzing a Yahoo Fantasy Hockey league in one place.

Project status: Early-stage concept. The application is not yet connected to Yahoo Fantasy and does not currently provide live league data.

Planned features

🏆

League standings

View team rankings, records, and league information in one place.

⚔️

Weekly matchups

Follow current head-to-head matchups and category or score progress where available.

🏒

Team rosters

Review roster positions, active players, bench players, and player information.

🔎

Free agents & waivers

Explore available players and compare their statistics when the data is available.

📊

Player analytics

Compare performance, including goals, assists, shots, hits, and blocks where supported.

📅

NHL schedule

Review upcoming games and help plan fantasy roster decisions.

How it is intended to work

1
Official authorization

The project intends to use the official Yahoo Fantasy Sports API and its approved authorization process, subject to Yahoo's approval and available permissions.

2
Read-only dashboard

The initial version is intended to read and display permitted league data. All roster changes and other league actions will continue to be performed directly on Yahoo Fantasy.

3
Personal use

The initial scope is one user and one Yahoo Fantasy Hockey league.

Project scope

This is an independent, personal project and is not affiliated with or endorsed by Yahoo or the National Hockey League. Access to Yahoo Fantasy data will depend on API approval, permissions, and applicable terms. No live data or Yahoo account connection is available on this page.
